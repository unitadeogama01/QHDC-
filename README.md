# Nombre del Proyecto: ¿Qué Hay de Comer? (QHDC!)

---

## DESCRIPCION

Proyecto para una aplicación web inteligente "¿Qué Hay de Comer? (QHDC!)", enfocada en la gestión de alimentos del hogar. Utiliza tecnologías de Inteligencia Artificial (IA) e Internet de las Cosas (IoT) para monitorear los alimentos disponibles, controlar fechas de caducidad, reducir el desperdicio de comida y generar recomendaciones de consumo y compra.

## OBJETIVO

Desarrollar una aplicación Web para "¿Qué Hay de Comer? (QHDC)", en un periodo de 4 meses con la Metodología SCRUM, utilizando HTML, CSS, JS, SQL, Inteligencia Artificial (IA) e Internet de las Cosas (IoT).

## FUNCIONALIDADES

-[] GESTION DE USUARIOS
-[] GESTION DE ALIMENTOS
-[] CONTROL DE FECHAS DE CADUCIDAD
-[] MONITOREO DE INVENTARIO MEDIANTE IoT
-[] RECOMENDACIONES DE CONSUMO MEDIANTE IA
-[] GENERACION DE LISTA DE COMPRAS
-[] GESTION DE RECETAS
-[] GESTION DE REPORTES
